# 월급 티커 (Salary Ticker)

월급을 입력하면 **지금 이 순간까지 번 돈**이 초 단위로 올라가는 작은 Windows 바탕화면 위젯입니다.

- 근무시간(출근~퇴근, 점심 제외)에만 오르거나, 24시간 내내 오르게 할 수 있습니다.
- 한국 공휴일(2026~2027년)과 급여 기간(예: 25일~다음 달 24일)을 반영합니다.
- 공제액을 입력하면 세후 금액으로도 볼 수 있습니다.
- 서버·계정·네트워크 없이 모든 데이터를 이 PC에만 저장합니다.

Tauri 2 + React + TypeScript로 만들었습니다.

## 주요 기능

**위젯**
- 오늘 번 돈(소수점 두 자리, 0.1초마다 갱신), 오늘 진행률, 다음 상태까지 남은 시간
- 상태: 출근 전 / 근무 중 / 점심시간 / 퇴근 / 휴일(공휴일이면 공휴일 이름)
- 이번 달(기간) 누적, 초당 금액, 시급 환산
- 세전/세후 표시
- 테두리 없는 둥근 카드로, 기본은 항상 위에 떠 있고 작업표시줄에는 나타나지 않습니다.
- 오른쪽 아래 모서리를 끌어서 크기 조절(180×44 ~ 340×230). 작게 할수록 하단 통계 → 버튼·상태 순으로 숨겨지고, 가장 작을 때는 금액 한 줄만 남습니다.
- 위치와 크기를 기억합니다. 저장된 위치가 화면 밖이면(모니터 분리 등) 주 모니터 오른쪽 아래로 돌아옵니다.
- 닫기 버튼은 종료가 아니라 숨기기입니다. 숨겨져 있는 동안은 화면 갱신을 멈춥니다.

**트레이 아이콘**
- 툴팁에 오늘 번 돈 표시
- 왼쪽 클릭: 위젯 보이기
- 메뉴: 위젯 보이기/숨기기, 클릭 통과, 설정, 종료

**기타**
- 퇴근 시각 알림(오늘 번 돈 포함)
- Windows 시작 시 자동 실행
- 창 배치: 항상 위 / 바탕화면 고정(다른 창 아래)
- 불투명도(20~100%), 클릭 통과(위젯을 눌러도 뒤의 창이 클릭됨)
- 중복 실행 방지: 이미 실행 중일 때 다시 실행하면 기존 위젯이 나타납니다.

## 설치

Windows 10/11 64비트용입니다.

1. [빌드](#빌드)로 만든 `Salary Ticker_0.1.0_x64-setup.exe`를 실행합니다.
2. 현재 사용자 계정에만 설치되므로 관리자 권한이 필요 없습니다.

- 코드 서명이 없어 Windows SmartScreen 경고가 뜰 수 있습니다. "추가 정보 → 실행"을 누르면 설치됩니다.
- 앱 화면을 그리는 Microsoft Edge WebView2가 필요합니다. Windows 10/11에는 대부분 이미 설치돼 있습니다.

## 사용법

### 첫 실행

저장된 월급이 없으면 위젯 대신 설정 창이 화면 가운데에 뜹니다.

| 항목 | 기본값 |
| --- | --- |
| 월급 (필수) | 2,156,880원 |
| 월 공제액 (선택) | 비어 있음 (0원) |
| 표시 기준 | 세전 |
| 계산 방식 | 근무시간만 |
| 출퇴근 시간 | 08:30 ~ 17:30 |
| 점심시간 제외 | 켬, 12:30 ~ 13:30 |
| 공휴일은 쉬는 날로 계산 | 켬 |
| 급여 기간 | 매월 1일부터 |
| 퇴근 시각 알림 | 켬 |
| Windows 시작 시 자동 실행 | 켬 |

입력하는 동안 아래쪽에 초당 금액과 시급이 미리 표시됩니다. "시작하기"를 누르면 설정 창이 닫히고 위젯이 나타나며, 트레이 위치를 알려 주는 알림이 한 번 뜹니다.

첫 실행에서 저장하지 않고 설정 창을 닫으면 앱이 종료됩니다.

### 설정 바꾸기

위젯의 톱니바퀴 버튼이나 트레이 메뉴의 "설정"으로 엽니다. 위젯이 가장 작은 크기일 때는 버튼이 없으니 트레이 메뉴를 쓰세요.

### 공제와 세전/세후

- 국민연금, 건강보험, 장기요양보험, 고용보험, 소득세, 지방소득세를 급여명세서 금액 그대로 원 단위로 입력합니다.
- 세율로 자동 계산하지 않으며, 빈칸은 0원으로 처리하고 합계는 자동으로 표시됩니다.
- **세후**를 고르면 `월급 − 공제 합계`를 기준으로 오늘 번 돈, 기간 누적, 초당 금액, 시급 환산을 모두 계산합니다.
- 공제 합계가 0원이면 세후를 고를 수 없고, 입력한 월급 그대로 계산합니다.
- 공제 합계가 월급 이상이면 저장할 수 없습니다.

### 클릭 통과를 켰을 때

클릭 통과가 켜져 있으면 위젯을 클릭하거나 옮길 수 없습니다. 끌 때는 트레이 메뉴의 "클릭 통과"를 누르세요.

## 계산 방식

매번 `(현재 시각, 설정)`만으로 처음부터 다시 계산합니다. 타이머로 금액을 더해 가지 않으므로 절전·시계 변경 후에도 값이 어긋나지 않습니다.

**근무시간 모드**
- 초당 금액 = 월급 ÷ (급여 기간의 근무일 수 × 하루 실근무 초)
- 근무일의 출근~퇴근 사이에만 오르고, 점심시간·출근 전·퇴근 후·주말·공휴일에는 멈춥니다.
- 급여 기간 마지막 근무일 퇴근 시각에 기간 누적액이 정확히 월급(세후면 세후 월급)이 됩니다.

**24시간 모드**
- 초당 금액 = 월급 ÷ 급여 기간 전체 초
- 급여 기간이 끝나는 순간 기간 누적액이 월급이 됩니다.

**급여 기간**
- 시작일이 1일이면 1일~말일, 25일이면 25일~다음 달 24일입니다.
- 그 달에 없는 날짜(예: 31일)는 그 달 말일부터 시작합니다.
- 기간이 바뀌면 새 기간의 근무일 수로 초당 금액을 다시 계산하므로, 달마다 초당 금액이 조금씩 다릅니다.

**공휴일**
- 2026~2027년 한국 공휴일 45일(대체공휴일, 선거일, 노동절 포함)이 [`src/engine/holidays-kr.json`](src/engine/holidays-kr.json)에 들어 있습니다.
- 이 범위 밖의 연도는 공휴일을 반영하지 않습니다.

## 제한 사항

- Windows에서만 빌드하고 확인했습니다.
- 근무 요일은 월~금으로 고정입니다(설정 화면에 없음).
- 퇴근 시각이 출근 시각보다 이른 야간 근무는 지원하지 않습니다.
- 테마는 Windows의 라이트/다크 설정을 따릅니다.

## 데이터 저장 위치

| 파일 | 내용 |
| --- | --- |
| `%APPDATA%\com.salaryticker.app\settings.json` | 설정 (월급, 공제, 근무시간 등) |
| `%APPDATA%\com.salaryticker.app\.window-state.json` | 위젯 위치와 크기 |

제거하면 자동 실행 등록(레지스트리 `HKCU\...\Run`)도 함께 지웁니다.

## 개발

### 준비물

- [Node.js](https://nodejs.org/) (npm 포함)
- [Rust](https://www.rust-lang.org/tools/install) (MSVC 툴체인)
- Microsoft C++ Build Tools, WebView2 — [Tauri 사전 준비](https://v2.tauri.app/start/prerequisites/) 참고

Node 24, npm 11, Rust 1.98에서 확인했습니다.

### 명령

```bash
npm install          # 의존성 설치
npm run tauri dev    # 개발 모드 실행 (Vite 1420 포트)
npm test             # Vitest 테스트
npm run build        # 프런트엔드 타입 검사 + 빌드
npm run tauri build  # 설치 파일 빌드
```

개발 모드 위젯에는 `DEV` 버튼이 있어서 가짜 현재 시각(출근 직전, 점심, 퇴근 직전, 주말 등)으로 바꿔 볼 수 있습니다. 개발 모드에서는 Windows 자동 실행에 등록하지 않습니다.

### 빌드

```bash
npm run tauri build
```

설치 파일은 `src-tauri/target/release/bundle/nsis/Salary Ticker_0.1.0_x64-setup.exe`에 만들어집니다. 현재 사용자 설치, 한국어 NSIS 설치 프로그램입니다.

### 폴더 구조

```
src/
  engine/      계산 엔진 (순수 함수, UI와 분리) + 공휴일 데이터
  settings/    설정 스키마·저장, 설정 창, 공제·세후 계산(pay.ts)
  widget/      위젯 UI, 크기별 레이아웃, 트레이 툴팁·퇴근 알림
src-tauri/
  src/         창·트레이·자동 실행·알림·위치 복원 (Rust)
  windows/     NSIS 설치 훅 (제거 시 자동 실행 정리)
```

### 테스트

`npm test`는 계산 엔진, 공휴일, 설정 폼, 공제·세후 계산, 위젯 레이아웃을 검사합니다. 주요 확인 항목은 다음과 같습니다.

- 근무시간 모드: 급여 기간 마지막 근무일 퇴근 시각의 누적액이 월급과 같은지(오차 1원 미만)
- 24시간 모드: 급여 기간 종료 시각의 누적액이 월급과 같은지
- 점심시간·주말·출근 전·퇴근 후에 증가가 0인지
- 월이 바뀌면 초당 금액이 새 달 기준으로 다시 계산되는지
- 급여 기간 시작일이 25일일 때 기간이 25일~다음 달 24일인지
- 월급 2,156,880원, 공제 338,710원, 세후일 때 마지막 근무일 퇴근 시각 누적액이 1,818,170원인지
